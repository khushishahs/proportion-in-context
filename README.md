# proportion-in-context
gamified experiment for children that assesses how their ability to reason about proportions is affected by the scenario's context 

# Run the experiment

1. Click **Download repository as ZIP**.
2. Open `proportion-in-context.html` in your web browser.
4. Turn on your sound and click **Start** once the experiment loads.

The 4open.science preview can fail to load the experiment even when JavaScript is enabled.
